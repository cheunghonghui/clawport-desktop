# ClawPort Desktop M2 验证记录

日期：2026-11-01。基于 DSH Desktop 0.2.1-rc.3，在 macOS 独立开发 Profile 验证。

## 交付内容

原生设置新增 ClawPort 账号入口；浏览器确认账号、工作区和设备后完成桌面授权。主进程管理加密刷新凭据、自动续期、重启恢复和退出撤销。云端新增设备授权 API、持久设备身份、会话轮换及浏览器确认页。

## 真实链路

数据库使用既有测试服务器上的独立临时 PostgreSQL 数据库和角色。控制 API、Web 与签名 OIDC 测试提供方运行在本地；浏览器走真实 Cookie 登录回调，数据库使用真实成员权限仓储。

1. 浏览器确认设备，桌面原生设置显示测试账号、律所、工作区和设备。
2. 授权兑换及 bootstrap 返回 200；刷新令牌轮换后旧访问令牌、旧刷新令牌返回 401。
3. 关闭并重新启动同一独立桌面 Profile，自动恢复连接，deviceId 和 runtimeId 保持不变。
4. 点击原生设置中的退出登录，界面回到未登录。数据库中的对应会话状态为 revoked，revoked_at 已写入。
5. 退出后本地加密凭据文件已删除，安装标识保留；服务链路验证撤销后的访问和刷新请求均被拒绝。

桌面截图保存在本地 `.superpowers/evidence/desktop-cloud-login/`，不随公共源码提交。
